# Монетки

PWA личного учёта финансов (замена CoinKeeper). Быстрый ввод трат: тап по монетке
категории → цифровая клавиатура → готово. Работает офлайн, данные принадлежат пользователю.

**Статус: v1.2.0.**

## Возможности

- Дашборд: сводный баланс (приведён к гривне по актуальному курсу Monobank), расходы месяца, план.
- Монетки категорий с лимитами и цветовой логикой CoinKeeper.
- Ввод: расход, доход, перевод между счетами, правка баланса.
- **Drag-ввод**: перетащил монетку счёта на категорию → лист расхода с выбранными счётом и
  категорией; на другой счёт → перевод. Сумму вводит пользователь, ничего не сохраняется без «Сохранить».
- Список операций по категории и счёту (тап по монетке/счёту) за месяц.
- Правка и удаление операции (тап по строке), балансы пересчитываются.
- Создание/редактирование категорий, счетов, источников доходов.
- Источник истины — **IndexedDB** на устройстве; работает без интернета.
- Устанавливается на домашний экран (PWA), светлая/тёмная темы, русский интерфейс.
- **Экспорт в vault** — единый JSON-снапшот `Финансы — Монетки.json`. Быстрый ручной синк:
  клик по индикатору синхронизации вверху запускает экспорт. На ПК — прямая запись в файл,
  на телефоне — сохранение под синхронизацию FolderSync.
- **Импорт из vault** — восстановление данных из JSON (десктоп: выбор папки vault целиком;
  телефон: выбор файла). Legacy `.md`-снапшоты ещё читаются ради миграции.

## Приватность

Реальные балансы и операции хранятся **только на устройстве (IndexedDB)** и в vault Obsidian.
В репозитории — лишь оболочка приложения и структура справочников; балансы в `js/seed.js`
обнулены. Секрет прослойки синхронизации в репозиторий не попадает (см. `config.local.js`,
он в `.gitignore`).

## Структура

```
index.html              оболочка
styles.css              стили
js/seed.js              стартовые справочники (балансы = 0)
js/db.js                IndexedDB — источник истины
js/rates.js             курсы Monobank (кэш + офлайн-фолбэк)
js/vault.js             экспорт/импорт vault (единый JSON; чтение legacy .md для миграции)
js/app.js               логика: рендер, ввод, drag-ввод, редакторы, экспорт/импорт
manifest.webmanifest    PWA-манифест
service-worker.js       офлайн-оболочка (network-first)
icons/                  иконки 192/512
```

## Локальный запуск

PWA требует http(s) (Service Worker + IndexedDB не работают с `file://`). Любой статический
сервер, например:

```bash
npx serve .
```

и открыть выданный `http://localhost:...`.

## Деплой на GitHub Pages

Settings → Pages → Source: ветка `main`, папка `/` (root). Через минуту приложение доступно
по адресу `https://<username>.github.io/<repo>/` — оттуда ставится на телефон. Service Worker —
network-first: свежий код подхватывается при сети, без очистки данных.

## Синхронизация в vault

Путь **без сервера**: «Экспорт в vault» (или клик по индикатору синхронизации) пишет единый
JSON-снапшот, а перенос в Google Drive/vault делает **FolderSync** на телефоне. IndexedDB
остаётся источником истины — приложение экспортный файл при обычной работе не читает
(только при явном «Импорт из vault»).

Экспорт (режим выбирается по устройству):
- **Прямая запись в файл** (ПК/устройства с File System Access): перезапись `Финансы — Монетки.json`.
- **Скачивание** (телефон): один файл `Финансы — Монетки.json`, дальше FolderSync доносит в vault.

Импорт заменяет данные приложения целиком: на десктопе можно выбрать папку vault — файлы
прочитаются за раз (JSON приоритетнее, старый `.md` поддержан ради миграции).
